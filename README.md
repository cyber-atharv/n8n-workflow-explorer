## Features
- **3D Scrollytelling Showcase:** Animated node graph, interactive category tunnel, live terminal simulation.
- **Direct GitHub Navigation:** 1-click jump from categories directly to workflow code in GitHub.
- **Visual Node Graph:** Dynamic SVG node architecture visualizer.
- **High Performance:** Unified requestAnimationFrame rendering loop with zero layout thrashing.
