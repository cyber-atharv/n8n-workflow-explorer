Live 3D interactive landing page and visual workflow explorer for the [Atharv n8n Workflow Library](https://github.com/cyber-atharv/n8n-workflow-library).

- **Landing Page:** [https://cyber-atharv.github.io/n8n-workflow-explorer/](https://cyber-atharv.github.io/n8n-workflow-explorer/)
- **Workflow Explorer:** [https://cyber-atharv.github.io/n8n-workflow-explorer/browse.html](https://cyber-atharv.github.io/n8n-workflow-explorer/browse.html)

## Connected Repository
- **Workflows Repository:** [cyber-atharv/n8n-workflow-library](https://github.com/cyber-atharv/n8n-workflow-library)
  - 1,044+ verified enterprise automations across 30 humanoid categories
  - Direct import into self-hosted and cloud n8n instances via Ctrl+V

## Features
- **3D Scrollytelling Showcase:** Animated node graph, interactive category tunnel, live terminal simulation.
- **Workflow Explorer:** Instant search by name, nodes, and integrations with keyboard shortcut `/`.
- **Visual Node Graph:** Dynamic SVG node architecture visualizer.
- **1-Click Import:** Instant JSON copying directly to n8n canvas.
